# Install from Marketplace

1. Open the **Marketplace** tab

![Marketplace tab with curated providers and Install buttons](/images/marketplace.png)

2. Search or browse the catalog
3. Click **Install** on a provider
4. Complete browser OAuth when prompted
5. Confirm the MCP appears under **Configure**

To connect a second account of the same provider, click **Add account** on its row, name it, and sign in — see [Marketplace → Add another account](../marketplace.md#add-another-account).

Install only succeeds after OAuth completes. For stdio or non-DCR servers, use **Configure → Add MCP** instead.
