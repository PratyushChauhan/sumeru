# sumeru-mcp

Node launcher for Sumeru’s portable binary. Downloads from [GitHub Releases](https://github.com/PratyushChauhan/sumeru/releases) on first run.

```bash
npm i -g sumeru-mcp
sumeru doctor
sumeru mcp-stdio
sumeru gui
sumeru servers list --json
sumeru keys token "work repo"
```

See the [repo README](../../README.md#npm-cli) for Cursor config and env overrides, and [docs/cli.md](../../docs/cli.md#manage-mcps-and-keys) for `servers` / `keys`.
